# CHECKMATE 아트 디렉션

## 스타일과 제작 경계

공모전·전시회에서 읽기 쉬운 고급 체스 액션을 목표로 한다. 일관된 재질과
절제된 조명, 선명한 기물 실루엣으로 품질을 높이며 과도한 제작 범위를 피한다.
아래는 승인된 비주얼을 구체화한 제작 지침이다. 최종 이미지나 애니메이션의 완성을 뜻하지 않는다.
1440×900 화면/보드 배치는 [승인 결정](DECISIONS.md)을 따른다.
제작 목록과 우선순위는 [ASSET_PLAN.md](ASSET_PLAN.md)에 둔다.

현재 Chapter 1 보드는 코드 도형으로 만든 절차적 시각 기반이다.
낮은 대비의 대리석 선, 타일 가장자리 명암, 금색 다중 프레임을 사용한다.
사진 질감·최종 일러스트·기물·이펙트·음향은 아직 없다.
Chapter 2~5의 코드 팔레트는 향후 교체를 위한 준비 데이터이며 완성 아트가 아니다.

장식보다 외곽 형태와 높이 차이를 먼저 읽게 한다. Queen의 펼쳐진 왕관과
King의 중앙 높은 표식을 분리한다. 공통 받침과 바닥 그림자는 점유 셀을 명확히 나타내며
공격 예고를 가리지 않는다. 기물이 실제로 더 많은 칸을 점유하는 것처럼 보이게 만들지 않는다.

밝은 칸/어두운 칸의 명도 차이를 유지한다. HUD 수치나 기능은 여기서 추가하지 않는다.

용암·붉은 보석은 낮은 밝기의 외곽 장식으로 사용해 위험 경고와 경쟁하지 않게 한다.
숲의 덩굴, 얼음의 결정은 셀 경계를 침범하거나 장애물처럼 읽히지 않아야 한다.

## 30종 기물 제작 방향

각 행은 외형/실루엣, 주요 색상, 식별 요소, 향후 공격 효과 방향을 지정한다.
효과는 기존 판정 범위에 종속되며 새로운 공격이나 상태이상을 뜻하지 않는다.

## 보스 콘셉트

왕실 체스 킹 / 고대 수목왕 / 빙설 군주 / 화산 군주 / 최종 보스 흑왕은
**아트 콘셉트용 임시 명칭**이다. 최종 이름이나 추가 능력으로 고정하지 않는다.
위 King 행의 소재와 왕관·인장을 챕터의 최고 수준으로 발전시킨다.
큰 몸체·강한 예고·전용 음향으로 위협을 주되 경고 셀과 기물 받침의 관계를 보존한다.
보스 HP·공격 타이밍·범위·이동 규칙은 이 문서에서 변경하지 않는다.

## 전투 이펙트 기준 — 향후 구현

| 상황 | 시각 피드백 | 음향/반응 | 검증할 점 |

| 일반 적중 | 짧은 적중 섬광, 스파크·충격 파티클 | 명확한 피격 반응과 적절한 타격음 | 경고 가림 방지, 히트스톱 필요성/시간은 추후 테스트 |

| 퍼펙트 패링 | 강렬한 금색 또는 청백 섬광, 확장 충격파 | 더 강한 타격감과 구별되는 성공음 | 일반 패링보다 큰 반경·명도·형태 차이, 과한 섬광 방지 |

색상만으로 성공/위협을 전달하지 않는다. 위험 셀은 명확한 외곽선·패턴과
명도 대비를 함께 사용하고, 피격/성공 효과는 판정 마스크와 시각 장식을 구분한다.
패링 성공 시 기절·공격 쿨타임 초기화·무적 시간은 기존 승인 규칙을 따른다.
이번 작업에서 관련 전투 코드·새 규칙·시간 수치를 만들지 않는다.

## 가독성·성능 수용 기준

- 75px 셀에서 6종 실루엣을 흑백 축소본으로도 구별한다. 기물 본체는 셀보다 작게 설계한다.
- 공격 경고는 타일보다 눈에 띄고 기물/플레이어/패링 피드백과 형태로 구별된다.
- 미세 무늬·반사광은 낮은 대비로 제한하고 보드 중심에 장식이 몰리지 않게 한다.
- HUD와 게임판은 비중첩을 유지한다. 장식 프레임은 보드 외부 여백을 사용한다.
- 타일은 틈 없이 채우며, row=0 아래쪽 좌표와 그리드 정렬을 유지한다.
- 불필요한 파티클·실시간 조명은 추가하지 않는다. 최종 에셋 로딩/변환은 매 프레임 수행하지 않는다.
- 현재 명령 목록은 테마 생성 시 캐시한다. 실제 Windows 성능/입력 반응은 GUI에서 별도 검증한다.
- 텍스처, 기물, 효과를 추가할 때 동일 장면의 가독성과 프레임 시간을 다시 측정한다.
  자동 팔레트/좌표 테스트 통과를 완성 아트나 플레이 품질 검증으로 표현하지 않는다.
