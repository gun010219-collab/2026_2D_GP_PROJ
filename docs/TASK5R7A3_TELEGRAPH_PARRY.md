# R7-A3 공격 전조와 패링 타이밍

R7-A2F는 사용자 실제 플레이 승인 후 `6632809643feda8fa81aa149f9e59975abab2fd5`로 GitHub main에 반영했다. 이번 A3의 사용자 플레이 검수는 대기 중이다.

## R7-A3F 사용자 승인

사용자가 A3C 실제 플레이를 확인하고 다음 단계 진행을 승인했다. A3·A3B·A3C의 전조, 타이밍 링 및 입력 안내를 확정했다. Stage24·25 성능과 P99 프레임 예산 초과는 R7-C 검수 및 최적화 항목이다.

## R7-A3C 전조 곡선과 패링 링

사용자 실기 피드백에 따라 최초 적색 채움을 일반 9% → 4%, Pulse 10.7% → 5%, 적색 테두리 알파를 140 → 90/255로 조정했다. 정규화한 원장 진행률을 p라고 할 때 19틱 이상 구간은 `p**1.75`로 보간한다. 초반에는 변화가 작고 충전 후반에는 증가가 빨라진다. 일반·퍼펙트 구간의 기존 채움·테두리와 금백색 L자 모서리를 유지한다.

플레이어를 대상으로 하는 공격의 남은 틱으로 발밑 링 하나를 그린다. 시작 반지름은 타일 폭의 0.58배이고 발동 직전까지 0.23배에 접근한다. 현재 연결 후보를 고르는 resolver를 공유한다. 연결 후보가 나오기 전에는 가장 임박한 위험을 표시한다. 실제 다음 입력이 일반 구간이면 청백색, 퍼펙트 구간이면 금백색 링과 `ALT`를 표시한다. 키 유지·쿨타임·무적 등으로 연결 안내가 나오지 않으면 위험색 링만 남는다. 해당 공격의 발동이나 취소, 범위 이탈 시 해당 링을 제거한다. 설정 및 포커스 전환에서 기존 입력 안내 정책을 따른다.

다음 입력과 현재 원장 틱은 한 틱 차이가 날 수 있다. Pulse가 현재 8틱 남은 프레임에서 발밑 `ALT`가 나타날 수 있는데, 새 입력이 처리되는 다음 틱은 이미 실제 퍼펙트 분류 범위인 7틱이다. 타일의 퍼펙트 모서리는 현재 7틱에서 나타난다. 입력 가능 시간이 늘어나지 않는다.

Stage4·9·14·19·24·25의 실제 전투를 숨김 Direct3D11로 캡처했다. Stage24 두 Queen과 Stage25 Pulse의 동일 틱 A3B 화면을 비교했고 기존 캡처를 보존했다. 25스테이지와 5보스 자동 캠페인 종료 결과, WAV 43개 해시는 기존과 일치한다. [실전 캡처와 해시](../artifacts/telegraph_r7a3c/manifest.json)

사용자는 현재 전투 밸런스에 만족하며 전체 난이도를 소폭 높여도 괜찮다고 의견을 남겼다. 난이도 상향 검토는 R7-B 인간 캠페인에서 진행한다.

전체 unittest **1,603개 / 368.512초 / 실패·오류·skip 0**이다. 기존 1,601개와 링 관련 신규 2개를 포함한다. 19·18·8·7·1·0틱 경계, 쿨타임·키 유지, 취소·다중 공격, 원장 범위와 기존 판정을 확인했다. 일반·`-O` 스테이지 검사, compileall과 Git 공백 검사도 통과했다.

동일한 숨김 Direct3D11에서 A3B 소스와 A3C를 같은 게임·렌더러로 교차 측정했다. 자세 갱신·렌더·Present 포함이며 각 모드의 워밍업 24프레임 이후 120프레임을 비교했다. 수치는 P50 / P95 / P99(ms)다.

| 표본 | A3B | A3C |
| --- | --- | --- |
| Stage24 교차 광선 · 틱 135 | 4.055 / 4.709 / 6.347 | 4.082 / 4.567 / 5.725 |
| Stage25 Pulse 퍼펙트 진입 · 틱 378 | 4.078 / 4.930 / 5.963 | 3.959 / 4.762 / 6.741 |
| Stage25 Pulse 발동 후 · 틱 389 | 4.259 / 4.521 / 5.133 | 4.258 / 4.840 / 5.702 |

이번 A3C 표본의 P95는 5.56ms 이내다. 세 표본의 P99가 예산을 넘었으므로 Stage24·25의 실제 Windows 반복 측정과 최적화는 R7-C에 남긴다.

## R7-A3B 초반 전조 보정

사용자 실기 피드백을 반영해 패링 구간 전 초기 채움은 15% → 9%, Pulse는 16.7% → 10.7%로 낮췄다. 최초 적색 테두리 알파는 170 → 140/255다. 보정량은 전체 예고의 절반까지 선형으로 줄어든다. 일반·퍼펙트 구간의 색상과 알파는 기존 값을 사용한다.

관련 테스트 28개를 통과했다. 숨김 Direct3D11 비교 14장 중 Stage24 두 Queen 초기 전조와 Stage25 Pulse 시작을 포함한 4장이 달라졌다. Pulse 중간·일반·퍼펙트 진입·발동 캡처는 해시가 일치했다. 자동 캠페인 25스테이지·보스 클리어 5회 결과도 기존과 일치했다. [동일 틱 전후 캡처와 해시](../artifacts/telegraph_r7a3b/manifest.json)

A3B 최종 소스에서 전체 unittest 1,601개를 367.863초에 통과했다. 실패·오류·skip은 0개다. 비교 캡처 14장의 위험 셀 수, 적중 틱, NEXT INPUT 상태·대상, 활성 VFX 목록도 전후가 일치했다. Windows 실기 재확인을 기다린다.

## 위험 셀과 다음 입력

위험 셀은 `EnemyAttackLedger`의 활성 전조에서 읽는다. 진행률은 `(tick - telegraph_start_tick) / (hit_tick - telegraph_start_tick)`이다. 발행 전, 발동 이후, 취소, 공격자 사망과 이전 세션의 전조는 사라진다. 셀마다 가장 임박한 공격 하나만 채운다. 같은 발동 틱은 원장의 공격 ID와 상태 키 순서로 선택한다.

| 남은 실제 틱 | 위험 셀 표현 |
| --- | --- |
| 19 이상 | 적색 채움을 9%에서 시작해 실제 진행률에 따라 높인다 |
| 18~8 | 45~63% 적색 채움과 밝은 적색 외곽선 |
| 7~1 | 65~78% 적색 채움, 금빛 외곽과 금백색 L자 모서리 네 개 |
| 0 | 전조 종료. 기존 발동 VFX와 실제 패링 결과 표시 |

Pulse는 보드 전체 100칸에서 적색 채움을 약 11~53%로 낮추고 외곽 광량을 줄였다. 보드 투영에 맞춰 타일 안쪽만 칠한다. 공격 VFX 지면 패스 위에 전조를 놓고 캐릭터·HP·피해 숫자는 그보다 위에 남긴다. 왕실의 금빛 발동과 퍼펙트 구간은 모서리 형태로, 용암·고딕의 적색 VFX와 전조는 셀 면·외곽 형태로 구별한다.

왼쪽 HP 패널의 **NEXT INPUT**은 플레이어 위치에서 다음의 실제 입력이 연결할 수 있는 대상을 보여준다. 고정 틱의 처리가 끝난 프레임에서는 다음 틱이 새 키가 처리될 가장 빠른 시점이므로, 보드 위험 등급과 한 틱 차이가 날 수 있다. 현재 화면이 1틱 전이라도 다음 입력이 발동 틱에 도착하면 `IMPACT NEXT TICK`만 표시할 수 있다. 대기, 쿨타임, 키 해제, 연결 후보 없음은 별도로 표시한다. 설정, 포커스 손실, 디스플레이 전환, 재시작 직후와 대기 중인 게임플레이 입력이 있는 프레임에서는 조작 안내를 숨긴다.

`CombatResolver.parry_target`은 실제 입력과 안내가 함께 사용한다. 살아 있는 공격자, 실제 플레이어 셀, `grade_for_delta`, 이미 연결된 공격과 원장 순서를 그대로 적용한다. 표시된 입력 등급은 성공 판정과 별개다. 공격 취소, 이동, 피해, 연결 결과와 반사 판정은 기존 전투 코드가 처리한다.

이미 적용된 무적 시간이 후보의 발동 틱까지 남아 있으면 `IMMUNE AT IMPACT`를 표시한다. 더 늦은 공격으로 안내 대상이 바뀌지 않으므로 실제 resolver가 연결할 공격과 어긋나지 않는다.

## 배치와 검증

100개 투영 타일의 정점과 채움·외곽·모서리 인덱스를 준비하고, 프레임마다 필요한 색과 인덱스만 채워 SDL 배치 한 번으로 그린다. 경고용 텍스처 생성과 파일 로딩은 없다. 지원하지 않는 SDL 기하 오류가 발생하면 기존 전조로 복귀한다.

검증 도구는 실제 Stage24 두 Queen과 Stage25 Pulse, Stage4·14의 Bishop을 진행한다. Stage25 첫 예고·중간 충전·일반·퍼펙트 진입·마지막 예고·미패링 발동·실제 퍼펙트 성공을 캡처한다. 같은 사건 배치에서 퍼펙트 음향과 반사 피해 2를 확인한다. [캡처와 틱·SHA-256](../artifacts/telegraph_r7a3/manifest.json)

### 자동 검증과 성능

최종 소스에서 전체 unittest **1,601개 / 346.785초 / 실패·오류·skip 0**이다. A3 신규 테스트 8개는 경고 경계와 증가, 무적·쿨타임·키 유지, 실제 후보와 중첩, 취소·사망·세션, 6기물 원장 범위, 60/144/180Hz, 배치·투영, 설정·포커스·F11을 검사한다. 일반·`-O` 스테이지 검사와 compileall, 아트 카탈로그, 문서 링크, Git 공백 검사도 통과했다.

숨김 Direct3D11에서 실제 자동 캠페인 25스테이지와 보스 클리어 5회의 결과가 기존 기록과 같다. 텍스처 258로드/258해제, 동시 최대 13개다. 임시 저장의 메뉴·해금·Stage21 이어하기·엔딩과 음악 전환도 같은 결과다. 기존 캡처 208장과 WAV 43개 해시가 일치했다. 새 캡처 14장은 독립 실행에서 일치했고, Stage24 A2B 모드의 캡처는 보관된 A2B 파일과 바이트가 일치했다.

동일한 1440×900 숨김 Direct3D11에서 틱과 자세 갱신·렌더·Present를 고정했다. 두 모드를 12프레임씩 교차하고 모드당 처음 24프레임 이후 120프레임의 P50 / P95 / P99를 비교했다. 단위는 ms다.

| 표본 | A2B | A3 |
| --- | --- | --- |
| Stage24 교차 광선, 틱 135 | 4.820 / 5.324 / 5.629 | 4.108 / 4.452 / 4.692 |
| Stage25 Pulse 퍼펙트 진입, 틱 378 | 5.939 / 6.752 / 6.952 | 4.029 / 4.634 / 5.114 |
| Stage25 Pulse 발동 후, 틱 389 | 4.422 / 4.978 / 5.585 | 4.429 / 4.982 / 5.666 |

이 표본의 P95는 모두 5.56ms 이하다. Pulse 발동 후 P99는 5.666ms다. 기존 Stage24·25 성능 결함과 실제 Windows 반복 측정은 R7-C에서 추적한다.
