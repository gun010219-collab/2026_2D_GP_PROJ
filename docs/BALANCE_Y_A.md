# Y-A 결정적 자동 전투 측정

각 Stage는 빌드별 누적stats로 독립 생성한다. 모든 HP/이동/공격/패링은 실제 규칙이며 HP0 fixture가 아니다.
기본타수는 각 적에 ceil(HP/기본공격력), 실제 적중수는 perfect+2/반사2/미스 등에 따라 다르다.
피격은 HP가 감소한 틱 수다. 실제 사람 완주·권장시간·장기밸런스 검증이 아니다.

측정 방법: `tests/balance_driver.py`의 `measure(style, stage, limit=3600)`을 호출한다.
한 사례의 상한은3600틱(고정60Hz 기준60초)이며 제한 도달 시 클리어로 간주하지 않는다.
BFS로 적에게 접근하고 실제 이동 쿨타임·공격·적중7틱 이내 경고 패링을 사용한다.
공격형은 ATTACK4회, 생존형은 HP3회/ATTACK1회, 회피형은 MOVE2회/ATTACK2회,
균형형은 ATTACK/HP/MOVE/ATTACK 순이다. Chapter2 시작 공격력은 해당 Chapter1 빌드에서 계승한다.
2026-11-13 최종 재검수에서 같은 설정으로40개를 다시 실행하여 전부 클리어했고 아래400개 셀이 모두 일치했다.
기존 측정값은 변경하지 않았다. 사용자 Windows GUI22/22 및 unittest/SDL dummy와는 별도 근거다.
