# CHECKMATE R3 기물 애니메이션

R2F `af14e7350e343ccec6ae9ad3156dc4532160ab29`에서 이어서 구현했다. 일반 실행과 공용 스테이지 선택 도구는 애니메이션을 켠다. 스테이지·챕터 아트 플래그는 기존 우선순위를 유지한다. `CHECKMATE_ANIMATION=0`은 같은 2.5D 보드를 정적 스프라이트로 그린다. 기존 개발 진입점의 기본값은 정적이며 `CHECKMATE_ANIMATION=1`로 애니메이션을 켤 수 있다.

## 기물별 Idle과 전투 자세

배치된 PNG의 UV를 하나의 연속 메시로 샘플링한다. 몸체, 장비, 천·갈기 영역마다 가중치와 위상을 달리해 움직인다. 새 부위 PNG나 별도 프레임을 준비하지 않았다. 갑주·천·장비의 독립 움직임은 메시 영역의 국소 변형이며 분리 관절 리깅은 후속 확장 대상이다.

Chapter1은 왕실 금속을 기준으로 사용한다. Chapter2는 갑주 응답을 낮추고 뿌리·덩굴에 해당하는 느슨한 영역 응답을 키운다. Chapter3은 결정 갑주 응답을 키우고 천 변형을 줄인다. Chapter4는 가장 느린 템포와 암갑 가중치, 적은 천 변형을 사용한다. Chapter5는 흑철과 찢긴 망토의 차이를 크게 둔다. 재질마다 템포·기하 변형과 국소 색조가 함께 달라진다.

## 실제 사건·시간·렌더링

- 메인 루프는 전투 입력 전에 `flow.enable_presentation()`을 호출한다. 입력과 고정 틱을 처리한 뒤 `drain()`을 프레임당 한 번 호출한다. 동일 불변 튜플을 향후 R4·R5 소비자도 받을 수 있다. 현재 전투·피해·패링 원장과 공개 사건 계약을 사용한다.
- (전투 세션, 스테이지 인스턴스)와 실제 사건 키를 사용하여 오래된 사건 및 중복 배치를 버린다. 여러 틱이 한 프레임에 들어오면 사건 시각과 현재 틱의 차이만큼 자세를 진행시킨다. 공격이 빗나가도 실제 발동 자세가 있으며, 피해 반동은 실제 피해 사건으로 제한한다.
- 우선순위는 사망 → 실제 기절 → 피격 → 확정 패링 → 공격 → 패링 준비 → 활성 원장 예고 → 이동 → Idle이다. 사망은 별도 표시 스냅샷이며 충돌·HP 라벨·공격·전투 상태에 관여하지 않는다. 세션이 바뀌면 이전 자세·시각·시체를 폐기한다. 클리어 또는 GAME_OVER에서도 마지막 사망 자세는 표시 시간으로 단기간 재생된다.
- 시간은 실제 렌더 경과 초를 사용한다. SETTINGS, 포커스 상실·복귀, F11, 진행 또는 재시작 프레임과 150ms 초과 공백을 단절 처리한다. 60Hz 판정과 180FPS 렌더 목표는 기존 루프를 사용한다.
- 발 기준 행을 메시 정점 행에 두고 지상 깊이와 그림자는 기존 B+12 논리점을 사용한다. HP는 움직인 몸체 상단을 따라가며 Knight 상승량은 몸체와 HP에만 반영한다. 공유 PNG 텍스처의 색상·알파·블렌드를 직접 바꾸지 않는다. 예상 메시 오류는 해당 세션의 기존 정적 2.5D로 복귀한다.

## 원본 검사와 Windows 검수

Chapter4 Knight 원화 최상행의 최대 alpha는 7, Chapter5는 103이며 두 파일 모두 최상행 alpha>128 픽셀은 0개였다. 원화에서 갈기와 뾰족한 장식 실루엣을 열어 확인했다. 폭이 있는 불투명 실루엣 절단은 확인되지 않았다. Chapter5는 반투명한 장식 끝점이 원화 경계에 닿으므로 F11과 도약에서 다시 확인한다. 기존 승인 텍스처를 보존했고 R3 신규 PNG는 검수 캡처다.

```powershell
# 저장소 루트의 플래그 없는 새 PowerShell
.\.venv\Scripts\python.exe main.py
.\.venv\Scripts\python.exe tools\chapter_art_play.py 25

# 같은 2.5D 아트를 정적으로 비교
$env:CHECKMATE_ANIMATION = '0'
.\.venv\Scripts\python.exe tools\chapter_art_play.py 25

# 숨김 기술 캡처를 새 경로에 재생성
$r3QaPath = Join-Path $env:TEMP ('checkmate-r3-' + (Get-Date -Format 'yyyyMMdd-HHmmss'))
.\.venv\Scripts\python.exe tools\animation_qa.py --renderer direct3d11 --output $r3QaPath
```
