# Task 3-F3A — 적 이동 반응성 통제 실험

### Task3-F3A 사용자 최종 확정

사용자가실험결과와기준선유지를승인했다. **Pawn132/Rook72/King72틱·기존예고/회복·HP프로필·HP이월그대로**, 공격속도상향은보류한다. 현재난이도평가는 **적절함**이며과거쉬움평가는HP상향전이력으로보존한다.
A/C는76/80·Stage18회피형새GAME_OVER로기각, B는77/80·피격악화없음이나이동횟수증가없음·Stage19공격/균형각36틱증가로채택하지않는다. 기준선77/80및기존실패408/395/838틱과연속공격20완료/생존16사망/회피18사망/균형19사망은보존한다.
런타임기능코드변경이없으므로Task3-F2 WindowsGUI30/30승인을유지하고동일검수를반복하지않는다. 이번실험후보의체감개선을검증했다고주장하지않는다. 후속개발우선순위는 **별도Task의Chapter5구현**이며Chapter5·Stage21~25·최종보스는아직미구현이다. 이번최종화에서구현하거나활성화하지않는다.
일반게임main은실험도구를자동호출하지않는다. 후보patch는명시적도구/테스트프로세스컨텍스트안에서만동작하고정상/예외종료시원래상수를복원한다. 별도프로세스밖의파일/실행중게임상태에적용되지않는다.

아래는실험단계당시의기록이며현재최종결정은위확정을따른다.


최신 사용자 난이도 평가는 **HP 상향 후 적절함**이다. 과거의 모든 스테이지가 쉬움 평가는 HP 상향 이전의 이력으로 보존한다. 일괄 이동/공격속도 10~20% 상향은 적용하지 않는다.

시작 main HEAD/origin `671439c78278698a1c08150bdc0c0f233a4afb3d`, 작업 트리·인덱스 깨끗함. 변경 전 전체1195개 116.638초 통과, 실패/오류/skip0. 기존HP프로필과원본JSON·AI·입력정책·강화·HP이월·공격시간·King이동·Pulse·60Hz/180FPS는모두보존한다.

## 측정과 재현 방법

[전체320건 독립 전투 및 후보별 연속 전투 원자료](BALANCE_ACTION_PACING.json). 기존 [HP 실험 원자료](BALANCE_HP_EXPERIMENT.json)는수정하지않았다. 기준선80건의적HP/기본타수/공격력/실제적중/피격/perfect/종료틱/잔여HP/상태는F2 after와모두일치했다. 연속플레이도20완료/16사망/18사망/19사망및각종료틱654/408/123/149를재현했다.

`tools/action_pacing_experiment.py`는기존measure()와real_campaign()을그대로호출한다. A→B→C는각각독립컨텍스트로순차측정했다. config파일을편집하지않고EnemyEncounter가생성시읽는import된두이동상수만프로세스내에서patch한다. 컨텍스트종료후원래값을복원한다. 전체전투정책·3600틱·Stage20공격형마지막HP선택은동일하다.

관측wrapper는원래resolver함수의인수/반환값을보존하고외부사전에위치·실제공격원장·피해반환값만기록한다. 정상전투와계측전투반환값일치를네프로필로검증했다. HP/이벤트/위치/입력/피해량을조작하지않는다.

- 이동수: 매정수틱해결뒤entity_instance_id별논리좌표변경수. Rook돌진/도약착지도포함하고보간프레임은제외한다.
- 공격개시: 실제발급된원장기록수(취소포함). 최초공격틱은최소telegraph_start_tick이며초기지연뒤기존AI실제예약시점이다.
- 동시개시/판정: 같은틱이벤트수의초과분합(sum(n-1)). 판정은실제resolve_enemy_attack호출기준으로피해가아닌패링/미스/무적도포함한다.
- 쿨다운중피격: 실제DamageResult로HP가감소한틱이next_parry_tick보다빠른건수. 단순한동시경고와구분한다.
- 독립전투는빌드최대HP시작, 연속전투는정상choose/enter_next_chapter로남은HP유지(HP강화만+1)다. 화면전환의전멸fixture를실제클리어측정에사용하지않는다.
- 위치중복은모든관측틱에서검사했다. 일반공격과Pulse시간상수는보존했고후보별Pulse동결/잔여타이머복원·결정성을별도테스트했다.
