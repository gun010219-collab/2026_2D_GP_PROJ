# CHECKMATE — 알려진 결함

## ART-BOARD-CH4-CH5-FRONT-OVERLAP

- 대상: Chapter4 Volcanic Kingdom / Chapter5 Gothic Dark Fantasy.
- 상태: **미해결 / OPEN**. R6c Fine-C 후에도 사용자가 작은 겹침을 보고했다.
- 분류: P2 시각적 접합 결함. 전투 판정 오류나 중앙100칸 대규모 침범으로 판정한 것이 아니다.
- 문제/재현: `tools/side_cleanup_review.py --fine`에서4/5→9→B 비교 시,
  앞면 중앙 문장·부조와 상판 하단 경계가 일부 겹쳐 보인다. 발광선·하이라이트·뾰족 윤곽이 접합 인식을 흐린다.
- 기대: 상판과 전면 패널이 동일 구조에 속하면서도 별개 면으로 명확히 읽히고 문장 전체가 상판 아래에 놓인다.
- 현재 결정: 정지 화면 보정은 종료한다. 디자인 방향은 승인하되 이 결함을 해결 완료로 바꾸지 않는다.
- 우선순위: **실제 렌더러 적용 시 수정**. Stage5 왕실 한정 통합 뒤 Chapter4/5 확장 전에 해결한다.
- 해결 방향: 공통 투영 좌표, 상판/전면 클리핑 마스크, 레이어 순서, 접합 림/패널 경계 구조 통합.
  원화의 불규칙 실루엣을 직사각형으로 겹쳐 놓는 방식과 추가 정지 샘플 반복으로 대체하지 않는다.
- 검증 기준: 실제 게임 화면의 이동·공격·패링·Pulse·창/전체 화면에서 겹침이 보이지 않고
  위험 셀·기물·HP·판정 보조의 가독성이 유지된다. 중앙100칸/게임 상태 불변 회귀와 사용자 GUI 확인이 필요하다.
- 개선 이력: Chapter2·3은 R6b 이후 사용자 평가상 크게 개선됐다. 이 결과는 유지하며 불필요한 재작업을 하지 않는다.

최종 애니메이션·사운드·저장/해금·정식 엔딩 등은 미구현 범위이며 이 아트 결함의 해결 여부와 구분한다.
