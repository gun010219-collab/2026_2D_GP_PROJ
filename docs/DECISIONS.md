# CHECKMATE 승인 결정

## Task 0-B — 화면 규격 변경 (2026-11-10)

사용자가 기존 1024×720에서 **1440×900**으로 변경하는 것을 최종 승인했다.
현재 화면 기준은 `config.py`에서 중앙 관리한다.

| 항목 | 승인 규격 |
| --- | --- |
| 게임 창 | 1440×900, 제목 CHECKMATE |
| 논리 보드 | 10×10, col/row 0~9, row=0은 아래쪽 |
| 타일 | 75×75px |
| 게임판 | 750×750px, 왼쪽 아래 (75,75), X=75~825 / Y=75~825 |
| 우측 UI 영역 | 465×750px, 왼쪽 아래 (900,75), X=900~1365 / Y=75~825 |

격자 중심은 `x = 75 + (col + 0.5) * 75`,
`y = 75 + (row + 0.5) * 75`로 계산한다 (`config.cell_center`).
기존 60px 타일 및 (40,60) 원점 규격은 이 결정으로 대체된다.
`stage_data.json`의 논리 좌표, 적 배치, ID 및 게임 규칙은 변경하지 않는다.
기존 PDF와 Task 0-A 기록은 과거 기준선 자료로 보존한다.

Task 0-B 부트스트랩의 ESC는 프로그램 종료다. 향후 실제 게임 상태에서의
ESC 일시정지 동작은 별도 구현하며 이번 작업에서 전투/UI를 구현하지 않는다.
