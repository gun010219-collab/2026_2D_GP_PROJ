# Task2-F Windows GUI 및 프레임 측정 절차

현재 상태: 사용자 직접 Windows GUI25/25 통과. 실패0·확인 불가0·미검수0. 아래 항목은 사용자가 실제 게임에서 확인했다. 자동 측정과 별도 근거다.

```powershell
$env:CHECKMATE_FRAME_STATS="1"
.\.venv\Scripts\python.exe main.py
Remove-Item Env:CHECKMATE_FRAME_STATS
```

게임을60초 이상 실제 조작한다. 콘솔은5초마다 target=180, 실제fps/mean_ms/p95_ms/p99_ms/max_ms/active_sim_hz 및samples를 출력하고 종료시 마지막 윈도를 출력한다.
통계는 최대600프레임의 rolling 윈도이며 전체60초의 통합P99가 아니다. 매5초 값을 함께 보존한다. 정지/종료/세션교체 구간은 활성Hz 집계에서 제외한다.
같은 장소·입력으로 메뉴/F11/포커스를 시험하고, 정상 전투 구간 active_sim_hz≈60인지 확인한다. 긴 정지의 backlog는 기존8틱 상한대로 버리므로 해당 구간은60Hz보다 낮게 관측될 수 있다.
정확한 경고/패링/피해 판정은 논리 셀 기준이다. 이동 중 작은 사각점은 실제 점유 중심이며 HP/STUN은 실루엣을 따른다. 공격/패링 입력 중 Player는 논리 위치로 정착한다.
모니터 모델·주사율·창/전체화면·GPU/CPU·Windows 전원모드·renderer/flags/VSync 출력값을 기록한다. SDL flags는 dummy 환경의 실제 디스플레이 주사율을 증명하지 않는다.
VSync 강제해제나 전투틱 변경을 하지 않는다.180FPS 미달이더라도 전투 속도와 시각적 품질을 함께 평가한다. 사용자 환경의CPU부하·발열·프레임지연 검수는 통과했다. 다양한 노트북/데스크톱 간 비교는 아직 미검증이다.

자동 실측 예: 숨김SDL dummy/software, 실제 perf_counter+sleep 약1.25초:166.57FPS/평균6.004ms/P95 6.074/P99 6.210/max6.755/활성시뮬레이션59.83Hz(samples206).
이는 초기 단기 테스트1회의 측정값이며 사용자 Windows창/60초 안정성/하드웨어 성능 결과가 아니다. SDL software flags13(VSync bit보고)을 기록했으며 실제모니터 VSync와 혼동하지 않는다.
