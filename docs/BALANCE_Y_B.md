# Task 1-Y-B 결정적 자동 전투 재측정

이 문서는 새 Pawn 접촉 규칙을 적용한 측정이다. [Y-A 원본 측정표](BALANCE_Y_A.md)는 변경하지 않았다.
원본 `tests/balance_driver.py`도 수정하지 않았다. 같은 `measure(style, stage, limit=3600)`으로
공격형/생존형/회피형/균형형 × Stage1~10의40개를 실행했다.
한 사례의 상한은3600틱이다. 각 Stage는 해당 빌드의 누적 능력치로 독립 생성하며 Chapter2는 공격 단계만 계승한다.
실제 HP·이동 쿨타임·공격·AI·원장·패링을 사용하며 HP0/전멸 fixture는 사용하지 않는다.
BFS 접근·공격 가능 시 SPACE에 대응하는 공격 요청·예정 적중7틱 이내 패링이라는 기존 입력 정책을 유지한다.
성장 유형별 선택 순서는 Y-A와 같다(공격4회, HP3/공격1회, 이동2/공격2회, 공격/HP/이동/공격).

결과: **40/40 클리어, 실패0**. Y-A 대비 전체 지표가 바뀐 사례는19개, 완료 틱 감소18개·증가1개·동일21개다.
피격 횟수는40개 모두 Y-A와 같으며 증가 사례는0개다. 새 접촉 예고를 정밀하게 패링하는 드라이버이므로
접촉 추가가 자동 플레이 난이도 상승으로 곧바로 이어지지는 않는다. 접근 경로·Pawn 정지·패링 보너스 변화가 타수와 완료 틱에 영향을 준다.
attack/Stage10은385→421틱으로 증가했지만 피격0·perfect2·BOSS_CLEAR다. 실패를 클리어로 바꾼 사례는 없다.
이 측정은 인간의 반응 시간·조작 부담·장기 밸런스·Windows GUI 검증이 아니다. 사용자 Windows GUI25/25는 별도 수동 검증으로 수령했다.
최종 재검수에서도 같은40개를 재실행하여400개 기본 측정 셀이 전부 일치했다. 기존 측정값은 변경하지 않았다.
